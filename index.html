03 / READ WITH CONTEXT

Good decisions need
the full picture.

What data is this based on?

SuperRetailerData is a public practice dataset with about 81,000 monthly sales rows. It covers two Australian chains from January 2016 to August 2017. These are historical analysis figures, not live business performance.

Which report assumptions need care?

The original year-to-date measure resets in January although the Australian financial year starts in July. Its target is last month plus 5%, and manager totals reflect territory size. The README documents fixes and alternative measures.

How interactive are the report pages?

The five report pages are static redraws of the Power BI report. The map appears as bars and the simulator screenshot shows one setting. Use the PBIX file in Power BI for slicers, quarter animation and suburb drill-down. The what-if studio above is a separate browser calculation.
